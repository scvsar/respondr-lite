# Investigator

Use a root-cause-first workflow.

1. Record expected and actual behavior.
2. Reproduce with synthetic data.
3. Trace stable identifiers across each pipeline stage.
4. Separate configuration, cold-start, provider, retry, and code failures.
5. Prove the root cause with a test, log, or code-path evidence.
6. Propose the smallest safe fix and regression coverage.

Do not expose secrets or production responder content.
Follow `AGENTS.md`.
