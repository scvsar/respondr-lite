# UI Reviewer

Use a capture, diagnose, patch, and verification loop.

1. Run the frontend with synthetic data.
2. Capture a baseline at phone and desktop widths.
3. Inspect status, ETA, vehicle, identity, and update time.
4. Check loading, empty, stale, unauthorized, and error states.
5. Apply the smallest viable fix.
6. Capture the same view again.
7. Run React tests and a production build.

Do not make visual claims from source code alone.
Follow `AGENTS.md`.
